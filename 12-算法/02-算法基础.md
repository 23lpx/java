# 算法基础

## 637. 数组常见题型有哪些？

**面试回答**

常见题型：遍历与统计、双指针（对撞/快慢）、滑动窗口、二分查找、前缀和、排序、哈希表配合（两数之和）等。数组题常围绕「有序性」和「下标」做文章。

**理解**

数组是线性的、按下标 O(1) 访问，很多技巧都建立在这个特性上：双指针（一个从前往后、一个从后往前，或快慢指针）处理两数之和、去重、反转；滑动窗口处理子数组/连续区间；二分要求数组有序；前缀和快速求区间和。先判断「是否有序」「是否连续区间」「是否要查找」来选择技巧。

**场景**

算法题「两数之和」用哈希表，「有序数组两数之和」用双指针，「最大子数组和」用滑动窗口或前缀和。

**常见追问**

- 数组核心技巧？（双指针、滑动窗口、二分、前缀和）
- 双指针有哪几种？（对撞、快慢）

**易错点**

数组技巧要「看场景选」：有序→二分/对撞指针，连续区间→滑动窗口，区间和→前缀和，别硬套。

## 638. 链表常见题型有哪些？

**面试回答**

常见题型：反转链表、找中间节点、判断是否有环、找环入口、合并两个有序链表、删除倒数第 N 个节点、两数相加等，核心技巧是「双指针（快慢指针）」和「哑节点」。

**理解**

链表不能随机访问，只能从头遍历，所以技巧集中：快慢指针（快指针走两步、慢走一步）找中点、判环；哑节点（dummy）简化头节点的处理（统一删除/插入逻辑）；反转链表用「前驱-当前-后继」三指针。链表题要画图理清指针关系，别丢指针。

**场景**

算法题「反转链表」用三指针迭代；「找链表中间节点/判环」用快慢指针；「删除节点」用哑节点简化边界。

**常见追问**

- 快慢指针解决什么？（找中点、判环）
- 哑节点干嘛？（简化头节点处理）

**易错点**

链表题关键技巧是「快慢指针 + 哑节点」；操作指针时注意顺序，先画图再写代码，避免断链。

## 639. 栈和队列常见题型有哪些？

**面试回答**

栈：括号匹配、单调栈（下一个更大元素）、表达式求值、用栈实现队列等；队列：BFS 层序遍历、滑动窗口最大值（单调队列）、用队列实现栈等。

**理解**

栈是「后进先出」，适合处理「最近相关性」「嵌套结构」：括号匹配、函数调用、单调栈找「下一个更大/更小元素」。队列是「先进先出」，适合「按顺序、按层」处理：BFS 用队列逐层扩展。单调栈/单调队列是进阶技巧（维护一个单调序列求极值）。

**场景**

算法题「有效的括号」用栈；「二叉树的层序遍历」用队列；「每日温度/下一个更大元素」用单调栈。

**常见追问**

- 栈适合什么？（括号匹配、单调栈、嵌套）
- 队列适合什么？（BFS、层序、滑动窗口）

**易错点**

栈处理「最近相关/嵌套」，队列处理「按顺序/按层」；单调栈/单调队列是高频进阶技巧。

## 640. Hash 表常见题型有哪些？

**面试回答**

常见题型：两数之和、统计频率、判断重复、字符/单词计数、映射关系（如罗马数字）、最长无重复子串（配合滑动窗口）等，核心是「O(1) 查找」和「去重/计数」。

**理解**

哈希表（HashMap/HashSet）的价值是「快速查找、快速判断存在、快速计数」。遇到「是否存在」「是否重复」「频率统计」「值→下标映射」这类需求，优先想到哈希。常和双指针、滑动窗口配合（哈希记录窗口内元素）。

**场景**

算法题「两数之和」用 HashMap 存补数；「存在重复元素」用 HashSet；「统计字符频率」用 HashMap 计数。

**常见追问**

- 哈希表擅长什么？（O(1) 查找、去重、计数）
- 什么时候想到用哈希？（是否重复/存在/频率）

**易错点**

哈希表核心是「用空间换 O(1) 查找」；遇到「重复/存在/计数/映射」需求优先考虑它。

## 641. 二分查找的基本写法是什么？

**面试回答**

二分查找在「有序数组」里查找目标：维护左右指针，每次取中间值和目标比较，小了右移左指针、大了左移右指针，直到找到或区间为空。模板是 while(left <= right) + mid 比较 + 收缩区间。

**理解**

核心模板：
```java
int left = 0, right = nums.length - 1;
while (left <= right) {
    int mid = left + (right - left) / 2; // 防溢出
    if (nums[mid] == target) return mid;
    else if (nums[mid] < target) left = mid + 1;
    else right = mid - 1;
}
return -1;
```
关键是「有序」和「区间收缩方向正确」，mid 用 left+(right-left)/2 避免整数溢出。还有变形：找左边界、右边界、第一个满足条件的位置。

**场景**

算法题「在排序数组中查找目标」「搜索插入位置」都用二分，把 O(n) 降到 O(log n)。

**常见追问**

- 二分前提？（数组有序）
- 复杂度？（O(log n)）
- mid 为什么写 left+(right-left)/2？（防溢出）

**易错点**

二分要求「有序」；循环条件是 left <= right、mid 防溢出、收缩区间方向要对，这些细节容易错。

## 642. 双指针常见场景有哪些？

**面试回答**

常见场景：①对撞指针（左右指针从两端向中间，处理有序数组两数之和、反转、回文）；②快慢指针（快慢速不同，处理链表找中点、判环、去重）；③同向指针（处理子数组、去重）。核心是「用两个指针减少暴力枚举的复杂度」。

**理解**

双指针本质是把 O(n²) 的暴力双循环优化成 O(n)。对撞指针：一左一右，根据条件移动一边（如有序数组两数之和，和大了右指针左移、小了左指针右移）；快慢指针：快指针探路、慢指针记录（链表判环、数组去重）。要根据题目判断用哪种。

**场景**

算法题「有序数组两数之和」对撞指针；「判断链表有环」快慢指针；「删除有序数组重复项」同向双指针。

**常见追问**

- 双指针分几类？（对撞、快慢、同向）
- 它优化了什么？（把 O(n²) 降 O(n)）

**易错点**

双指针要分清「对撞/快慢/同向」三种场景；它把暴力二重循环优化成线性，是高频技巧。

## 643. 滑动窗口常见场景有哪些？

**面试回答**

滑动窗口用于处理「连续子数组/子串」问题，如最长无重复子串、最小覆盖子串、长度最小的子数组、找异位词等。核心是维护一个左右边界可伸缩的窗口，满足条件就扩大、不满足就缩小。

**理解**

滑动窗口是双指针的延伸，专门处理「连续区间」：右指针扩大窗口加入元素，当窗口不满足条件时左指针收缩移除元素，在移动过程中记录最优解。关键是「什么时候扩大、什么时候收缩、怎么更新结果」。常配合哈希表记录窗口内元素。

**场景**

算法题「最长无重复子串」用滑动窗口 + HashSet，重复就缩左边界；「最小覆盖子串」用滑动窗口 + 计数。

**常见追问**

- 滑动窗口适合什么？（连续子数组/子串）
- 核心操作？（右扩、左缩、更新结果）

**易错点**

滑动窗口专门解决「连续区间」；关键是理清「扩大条件、收缩条件、结果更新时机」，别漏更新或更新错位置。

## 644. BFS 的基本写法是什么？

**面试回答**

BFS（广度优先搜索）用队列逐层遍历：起点入队，循环取出队头，把它的相邻未访问节点入队，直到队列为空。核心是「队列 + 访问标记」，适合最短路径、层序遍历。

**理解**

模板：
```java
Queue<Node> queue = new LinkedList<>();
queue.offer(start);
visited.add(start);
while (!queue.isEmpty()) {
    Node cur = queue.poll();
    for (Node next : cur的相邻节点) {
        if (!visited.contains(next)) {
            visited.add(next);
            queue.offer(next);
        }
    }
}
```
求最短距离时，通常记录「层数」，每层遍历完距离 +1。BFS 保证「第一次到达某节点就是最短路径」（无权图）。

**场景**

算法题「二叉树层序遍历」「最短路径」「最小步数」用 BFS，逐层扩展找到最短距离。

**常见追问**

- BFS 用什么结构？（队列）
- 它适合求什么？（无权图最短路径、层序）
- 为什么能求最短？（逐层扩展，先到先短）

**易错点**

BFS 核心是「队列 + 访问标记」；求最短路径要记「层数/距离」，别忘标记已访问防止重复入队。

## 645. DFS 的基本写法是什么？

**面试回答**

DFS（深度优先搜索）用递归（或显式栈）沿一条路径走到底，再回溯探索其他分支；核心是「递归 + 访问标记 + 回溯」。适合路径搜索、连通性、树的深度遍历等。

**理解**

模板（递归）：
```java
void dfs(节点 node) {
    if (终止条件) return;
    访问/处理 node;
    visited.add(node);
    for (next : node的相邻节点) {
        if (!visited.contains(next)) dfs(next);
    }
}
```
DFS 一条路走到黑、撞墙回溯。和回溯的区别：DFS 强调「遍历/搜索」，回溯强调「尝试 + 撤销选择」。DFS 常需要标记访问，递归栈就是隐式的栈。

**场景**

算法题「岛屿数量」用 DFS 淹没连通区域；「二叉树的深度优先遍历」「路径总和」用 DFS 递归。

**常见追问**

- DFS 用什么实现？（递归，或显式栈）
- 和 BFS 区别？（DFS 一条路到底，BFS 逐层）

**易错点**

DFS 是「递归 + 标记 + 回溯」；注意标记访问时机、别忘回溯时撤销（回溯场景），避免死循环。

## 646. 回溯的基本模板是什么？

**面试回答**

回溯是一种「试错 + 撤销」的搜索：递归地做选择，探索下去，不行就撤销选择、换一个再试，直到找到解或穷尽。模板是「做选择 → 递归 → 撤销选择」。

**理解**

模板：
```java
void backtrack(路径, 选择列表) {
    if (满足结束条件) { 记录结果; return; }
    for (选择 : 选择列表) {
        做选择;
        backtrack(路径, 新选择列表);
        撤销选择; // 关键，恢复现场
    }
}
```
回溯用于「求所有组合/排列/子集」这类枚举问题，核心是「撤销选择」恢复现场，否则状态会污染其他分支。常配合剪枝优化。

**场景**

算法题「全排列」「组合」「子集」「N 皇后」「括号生成」都用回溯，穷举所有可能并剪枝。

**常见追问**

- 回溯核心三要素？（做选择、递归、撤销选择）
- 和 DFS 关系？（回溯是 DFS + 撤销，用于求所有解）

**易错点**

回溯关键是「撤销选择」恢复现场；忘撤销会导致结果错乱。它是「枚举所有解」的通用模板。

## 647. 二叉树常见遍历方式有哪些？

**面试回答**

两种大类：①深度优先（DFS）：前序（根-左-右）、中序（左-根-右）、后序（左-右-根）；②广度优先（BFS）：层序（一层一层）。各有递归和迭代两种写法。

**理解**

前中后序是「根节点访问顺序」不同：前序先访问根，中序在中间（二叉搜索树中序有序），后序最后访问根（适合自底向上）。层序用队列逐层。三种深度遍历递归写法简单，迭代写法用栈。它们常用于树的遍历、构造、路径问题。

**场景**

算法题「二叉树中序遍历」得到有序序列（BST）；「层序遍历」用队列；「后序遍历」用于计算子树高度/删除树。

**常见追问**

- 三种深度遍历区别？（根节点访问顺序）
- 中序有什么特性？（BST 中序有序）
- 层序用什么？（队列）

**易错点**

前/中/后序区别在「根访问时机」；BST 中序遍历有序是常考点；层序是 BFS 用队列。

## 648. 堆通常解决什么问题？

**面试回答**

堆（优先队列）用于「动态维护最值」：快速拿到最大/最小元素，常用于 Top K 问题、合并 K 个有序链表、求中位数、任务调度等。取最值是 O(1)，插入/删除是 O(log n)。

**理解**

堆能「动态」维护一个集合的最值，比「每次排序 O(n log n)」或「每次扫描 O(n)」高效。典型 Top K：求最大 K 个用小顶堆（维护 K 个，堆顶是 K 个里最小的，来了更大的就换掉堆顶）；求最小 K 个用大顶堆。Java 里用 PriorityQueue。

**场景**

算法题「数组中最大的 K 个元素」用小顶堆；「合并 K 个有序链表」用小顶堆每次取最小；「数据流中位数」用两个堆。

**常见追问**

- 堆解决什么？（动态维护最值）
- Top K 怎么用堆？（求最大 K 用小顶堆）

**易错点**

「求最大 K 用最小堆、求最小 K 用最大堆」容易反；堆是「动态取最值」，比反复排序高效。

## 649. 动态规划的基本思路是什么？

**面试回答**

动态规划（DP）把大问题拆成有重叠的子问题，用数组记录子问题结果避免重复计算。核心步骤：①定义 dp 数组含义；②找状态转移方程（递推关系）；③确定初始值/边界；④按顺序填表、返回结果。

**理解**

DP 解决「最优解/方案数」，关键是「状态定义」和「转移方程」。经典如爬楼梯：dp[i] = dp[i-1] + dp[i-2]（到第 i 阶的方法数）。步骤：明确 dp[i] 表示什么 → 写出 dp[i] 怎么由前面的推出 → 初始化边界 → 从小到大算。典型题：爬楼梯、最长递增子序列、背包、编辑距离。

**场景**

算法题「爬楼梯」「最长递增子序列」「打家劫舍」都用 DP，先想清楚状态和转移方程再写代码。

**常见追问**

- DP 核心两步？（定义状态、写转移方程）
- 它解决什么？（有重叠子问题的最优解/方案数）

**易错点**

DP 关键是「状态定义 + 转移方程」，想清楚再写；别一上来就写代码，边界/初始化容易漏。
