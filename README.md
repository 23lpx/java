# Java 后端实习面试知识库

这是一个以 Obsidian Vault 形式维护的 Java 后端求职知识库，服务于 Java 后端实习的学习、复习、项目追问和模拟面试。

## 项目目标

> 准确性优先于完备性，求职价值优先于题目数量。

知识库不是 Java 百科全书，也不以收录题目数量为目标。核心内容需要做到：结论准确、条件明确、版本清晰、能够复述，并能关联真实项目或典型工程场景。

## 使用方式

1. 克隆或下载本仓库。
2. 在 Obsidian 中选择“打开本地仓库”。
3. 从 [00-总目录.md](00-总目录.md) 进入知识地图。
4. 按 [00-第一轮学习队列.md](00-第一轮学习队列.md) 同时推进六条学习线，并用每日模板记录闭卷结果。
5. 第一轮覆盖后进入 [00-第二轮学习队列.md](00-第二轮学习队列.md)，并按 [00-P0母题与追问链地图.md](00-P0母题与追问链地图.md) 训练连续追问，只根据真实断点复习。
6. 先用 [00-简历证据与追问地图.md](00-简历证据与追问地图.md) 校准项目真实性，再从 [00-模拟面试与反馈入口.md](00-模拟面试与反馈入口.md) 执行六线模拟面试，把追问断点回流第二轮队列。
7. 仅根据闭卷或面试证据更新对应笔记 Frontmatter 中的 `status`。

建议使用 Obsidian 阅读。仓库内部大量使用 `\[\[Wikilink\]\]`、标题锚点和 YAML Frontmatter，其他 Markdown 阅读器可能无法完整呈现双向链接。

## 当前内容

V1.1 已完成全部 649 道题的第一轮准确性校准。V1.2 正在把准确内容转化为求职知识地图、证据驱动复习、项目追问和可复盘的模拟面试能力。

- Java 基础、集合与 HashMap
- Spring、Spring Boot、Spring MVC、AOP 与事务
- MyBatis
- MySQL 索引、事务、MVCC 与锁
- Redis 与缓存设计
- Web、认证、ThreadLocal、HTTP 与网络
- 外卖项目业务与第三方支付
- JVM、Java 并发、开发工具、中间件与算法

## 内容结构

核心问题逐步统一为以下结构：

- 面试回答
- 原理与理解
- 成立条件与边界
- 实际场景
- 常见追问
- 易错点

“实际场景”必须区分真实项目场景、通用工程场景和不适用场景，不能把通用案例表述成个人经历。
